Vim常用指令

# 1. 基本操作

语法 解释 示例
i 插入模式，从光标前插入 iHello插入 "Hello"
a 插入模式，从光标后插入 aWorld插入 "World"
ESC 退出插入模式，回到普通模式 -
:w 保存文件 :w保存当前编辑文件
:q 退出文件 :q退出编辑器（若无改动）
:wq 保存并退出 :wq保存文件后退出
:q! 强制退出（不保存） :q!放弃修改退出

# 2. 移动光标

语法 解释 示例
h, j, k, l 左、下、上、右移动 5j向下移动5行
0 / ^ 移动到行首 / 第一个非空白字符 ^
$ 移动到行尾 $
gg / G 移动到文件开头 / 结尾 gg,G
:10 移动到第10行 :100到第100行

# 3. 搜索与替换

语法 解释 示例
/word 向下搜索 word /TODO
?word 向上搜索 word ?error
n / N 下一个 / 上一个匹配 /test后按n
:%s/old/new/g 全文替换 old 为 new :%s/foo/bar/g
:%s/old/new/gc 全文替换 old 为 new ，但是每个会询问是否替换 :%s/foo/bar/gc
:s/old/new/g 当前行替换 old 为 new :s/foo/bar/g

# 4. 删除与复制粘贴

语法 解释 示例
x 删除光标处字符 x
dd 删除当前行 dd
yy 复制当前行 yy
p 粘贴到光标后 小p
P 粘贴到光标前 大P
dG 删除当前行到文件尾 dG

# 5. 多文件/窗口操作

语法 解释 示例
:e filename 打开新文件 :e test.txt
:vsp filename 垂直分屏打开文件 :vsp test.txt
:sp filename 水平分屏打开文件 :sp test.txt
ctrl-w w 在窗口间切换 ctrl-w w
:q 关闭当前窗口 :q

# 6. 其他常用

语法 解释 示例
u 撤销 u
ctrl-r 重做 ctrl-r
. 重复上一个操作 .
:set number 显示行号 set number
:set paste / :set nopaste 粘贴模式 / 关闭粘贴 用于从剪贴板粘贴时避免缩进错乱
v 进入字符可视模式，从光标开始选择字符 小v→ 使用方向键或 hjkl 选择文本
V 进入行可视模式，选中整行 大V→ 选中当前整行，继续上下选中更多行，可配合 d 删除，y 复制，> 缩进等操作
