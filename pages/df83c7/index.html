前后端部署

# JFINAL 版本

# 前端配置

# 1. 创建 Dockerfile

# 使用 Nginx 基础镜像
FROM nginx:alpine

# 删除默认的 Nginx 配置文件
RUN rm -rf /etc/nginx/conf.d/default.conf

# 复制自定义的 nginx 配置文件到容器
COPY nginx.conf /etc/nginx/nginx.conf

# 复制打包后的前端文件到 Nginx 容器
COPY dist /usr/share/nginx/html/qianduan

# 暴露 Nginx 默认的端口
EXPOSE 16000

# 2. 创建 nginx.conf

worker_processes  1;

events {
    worker_connections  1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;

    sendfile        on;
    keepalive_timeout  65;

    # 前端服务
    server {
        listen       16000;
        server_name  localhost;

        root /usr/share/nginx/html/qianduan;
        index index.html;

        location / {
            try_files $uri $uri/ /index.html;
        }
    }

    # 文件服务器
    server {
        listen       18080;
        server_name  localhost;

        root /ybasefile;
        autoindex on;  # 启用目录浏览
        autoindex_exact_size off;  # 以 KB/MB 显示文件大小
        autoindex_localtime on;  # 以本地时间显示文件修改时间

        location / {
            try_files $uri $uri/ =404;
        }
    }
}

# 后端配置

# 1. 创建 Dockerfile

# 使用 OpenJDK 21 作为基础镜像
FROM openjdk:21-jdk-slim

# 设置工作目录
WORKDIR /app/houduan

# 复制 target 目录到容器中
COPY target/wenjie-release/wenjie /app/houduan/

# 设置类路径，包含 config、lib 和 JAR 文件
ENV CLASSPATH=/app/houduan/config:/app/houduan/lib/*:/app/houduan/lib/wenjie-0.0.1-SNAPSHOT.jar

# 暴露端口
EXPOSE 6157

# 设置容器启动命令，启动主类
ENTRYPOINT ["java", "-Xverify:none", "-cp", "/app/houduan/config:/app/houduan/lib/*:/app/houduan/lib/wenjie-0.0.1-SNAPSHOT.jar", "com.yi.common.config.MyConfig"]

# 2. config.properties 配置

# 启动

# 1. 配置docker-compose.yml

version: '3.8'

services:
  # 后端服务
  backend:
    build: ./houduan
    ports:
      - "6157:6157"
    volumes:
      - "D:/ybasefile:/ybasefile"  # **挂载 Windows D 盘**
    restart: always

  # 前端 & 文件服务器
  frontend:
    build: ./qianduan
    ports:
      - "16000:16000"  # 前端服务
      - "18080:18080"  # 文件服务器
    volumes:
      - "D:/ybasefile:/ybasefile"  # **挂载 Windows D 盘**
    depends_on:
      - backend
    restart: always

# 2. 容器一键启动

  • 整体目录结构如下：
.
├── houduan
|   ├── target          # 编译后生成的 后端 文件夹
│   └── Dockerfile    
├── qianduan
|   ├── dist            # 编译后生成的 前端 文件夹
|   ├── Dockerfile          
│   └── nginx.conf      # Nginx 配置文件
└── docker-compose.yml

在docker-compose.yml同级目录打开命令行，执行命令：

docker-compose -p myproject up -d --build
  • 部署完成后点击：http://localhost:16000 (opens new window) 测试是否部署成功

# 遇到的问题

  • 数据库访问不了，最后检查是无权限，开放权限即可。
# 查看权限，确认 host 是否为 %
SELECT user, host FROM mysql.user;
# 如果没有，开放权限
CREATE USER 'root'@'%' IDENTIFIED BY 'root';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
